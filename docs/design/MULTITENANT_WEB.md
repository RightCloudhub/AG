# 多租户 Web 页面设计记录

沿用 `UI_DESIGN.md` §10 起的推理笔记本与靛夜 / 晨纸主题。
应用设计技能抽取：Editorial greeting，seed `1644797140`，保留既定配色与字体。
选择原因：个人进入笔记本、管理员维护小团队，两者都需要清晰的当前身份和下一步操作。

- 对象：用户（邮箱、名称）、工作空间（名称、角色）、成员、邀请、服务密钥、登录会话。
- 新账号只有一个个人空间；不展示虚构业务量，列表总数来自响应。
- 管理员主要在桌面维护成员；问答与邀请也须在 390px 手机上可用。
- 登录页回答“如何进入我的笔记本”，表单是主要操作；注册直接建立个人空间。
- 品牌面貌：已有三节点路径标志、衬线问题标题，产品自己的“问题 → 路径 → 证据”。
- 左侧品牌区以文字说明推理用途；右侧表单只收集完成当前操作所需的信息。
- 设置页按资料 / 安全 / 成员 / 密钥 / 空间导航，名称与说明左列、操作右列。
- 成员行呈现姓名、邮箱与真实角色；最后管理员保护由后端裁决并就地说明。
- 密钥创建后仅当页显示一次；撤销需点名确认，表格保留状态与时间。
- 工作台始终显示空间和用户名称；历史只加载当前用户与空间的分区。
- 请求中、空列表、字段错误、403、404 与会话失效均有明确文案和可用的下一步。

⚠ 设计差异：已批准品牌使用靛色和三种字体角色，覆盖技能的默认色彩/字体限制。
保留现有三栏工作台，而非把抽取的居中问候布局扩展到长时间工作的业务页面。
数据全部连接实际本地 API；截图测试账号和临时数据库不作为产品预置内容。
