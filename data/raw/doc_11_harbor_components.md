# Harbor Components Profile

Harbor Components is a power-electronics manufacturer headquartered in Busan.

Harbor Components was founded by Lee Min-jun in 2012. Lee Min-jun is also the CEO of Harbor Components.

Harbor Components produces the HC-Power Module, which is used in QuantumEdge Server. Harbor Components supplies power modules for QuantumEdge Server and supplies only NovaTech Industries in the enterprise server segment.

Harbor Components participated in Harbor Partnership 2024 together with NovaTech Industries and Apex Holdings.
